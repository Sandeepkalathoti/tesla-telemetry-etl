# Tesla Telemetry Data Dictionary

This document describes the fields available in the Tesla vehicle telemetry dataset.

## Dataset

Source format: JSON Lines (`.jsonl`)

Each line represents one telemetry event generated by a Tesla vehicle.

## Fields

| Field | Data Type | Description | Example |
|---|---|---|---|
| `vehicle_id` | String | Unique identifier of the Tesla vehicle | `TESLA001` |
| `timestamp` | Timestamp | UTC timestamp when the telemetry event was recorded | `2026-08-15T10:00:00Z` |
| `speed` | Float | Vehicle speed at the time of the event, measured in km/h | `65.5` |
| `battery_level` | Float | Remaining vehicle battery percentage | `82.3` |
| `latitude` | Float | GPS latitude of the vehicle location | `17.3850` |
| `longitude` | Float | GPS longitude of the vehicle location | `78.4867` |

## Data Quality Rules

The following validation rules are applied to the telemetry data:

### vehicle_id

- Must not be null.
- Must be a non-empty string.
- Should uniquely identify a vehicle.

### timestamp

- Must not be null.
- Must contain a valid timestamp.
- Timestamps are expected to be in UTC.

### speed

- Must be numeric.
- Must be greater than or equal to `0`.
- Values should represent speed in km/h.

### battery_level

- Must be numeric.
- Must be between `0` and `100`.
- Represents the remaining battery percentage.

### latitude

- Must be numeric.
- Must be between `-90` and `90`.

### longitude

- Must be numeric.
- Must be between `-180` and `180`.
